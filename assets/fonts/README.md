Static TrueType cuts of the site's typefaces, used only to render the link
preview card (`app/opengraph-image.tsx`). The image renderer cannot read the
WOFF2 or variable files that `next/font` serves, so these are separate copies.

All three are licensed under the SIL Open Font License 1.1 and were downloaded
from Google Fonts:

- Cormorant Garamond Light — Christian Thalmann
- Caveat Medium — Impallari Type
- Inter Medium — Rasmus Andersson
